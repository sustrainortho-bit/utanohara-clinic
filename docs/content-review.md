# 現行サイトから流用した本文の確認事項（医療広告ガイドライン）

作成日: 2026-09-20 / 担当医・院長にご確認いただくためのメモです。

新サイトの既存ページの本文は、ご指示どおり**現行サイトの文言をそのまま流用**しています（文言は変更していません）。
`node scripts/scan-claims.mjs` で、ガイドライン上の確認が必要になりそうな表現を機械的に洗い出した結果（43件）のうち、特に見ていただきたいものを下にまとめました。
最終的な適否は院長・所管の保健所等への確認が必要です（当メモは法的助言ではありません）。

## A. 優良性・他院との比較を思わせる表現

| ページ | 表現（抜粋） |
|---|---|
| クリニックについて | 「高度医療機器を併設し、最新の物理療法機器を備え」「レベルの高い医療をご提供し」 |
| 設備のご紹介 | 「最新のオープン型MRI装置」「最新鋭の骨密度測定装置」「各種最新の機器を備えております」 |
| リハビリテーション科 | 「経験豊富な理学療法士が…最適なリハビリ」「最新の物理療法機器」「最新の技術の習得」 |
| 整形外科一般 | 「患者さまにとってベストな治療方法」 |
| 骨粗鬆症治療 | 「個々の患者様に最適な薬物選択」 |
| スポーツ整形外科 | 「その診断治療はスポーツ専門医に任せるのが安心です」 |

対応案: 「最新」「高度」「最適」「ベスト」などを外し、事実（機種名・導入年・できること）の記述に置き換える。

## B. 効果の断定・数値・根拠が必要な表現

| ページ | 表現（抜粋） | 確認したい点 |
|---|---|---|
| 設備のご紹介 | 骨折超音波治療器「骨癒合期間を約40％短縮できます」 | 数値の根拠（出典・条件）の明示。断定的でない書き方。 |
| 設備・リハビリテーション科 | 「より高い治療効果を期待できます」「効果的な治療やトレーニングを可能にします」 | 「期待できます」の範囲か。個人差の注記。 |
| 膝の再生療法 | 「欧州で既に治療法として承認されています」「国際的に権威のある学術雑誌に報告され、有効性の確認が進んでいます」「安心できる治療の選択肢」 | 出典の明示（誰が・いつ・どの試験か）。「権威のある」「安心」の表現。 |
| スポーツ整形外科 | 「完治が難しくなる可能性も高まります」 | 不安をあおる表現にならないか。 |

## C. 自由診療（膝の再生療法・ACP PRP療法）の表示

現行ページには、費用、注意事項（治療効果には個人差がある、長期の治療効果は確認されていない 等）の記載があります。ガイドラインの限定解除要件（治療内容・費用・主なリスク・副作用・問合せ先）と、再生医療等安全性確保法に基づく届出内容に沿った表示になっているか、ご確認をお願いします。

## 対応の進め方

1. 上記A・Bについて、書き換えの方針（外す／事実の記述に置き換える／根拠を明示する）を院長・担当医が決める。
2. 決まった方針に沿って、私が文言を修正する（現行サイトの表現は `_archive/` に原本を残してあります）。
3. 新規に作る疾患解説・専門外来のページは、最初からこの方針で書きます。
